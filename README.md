* Управление:

  * ходьба: WASD и стрелки.
  * прицел: правая кнопка мыши.
  * пригнуться: ctrl
  * бежать: shift
  * прыгать: пробел
* Что реализовано (по разделам ТЗ):

* Персонаж ходит и бегает за ним ездит камера, есть индикатор здоровья, почти дореализована логика врагов (пока только ходят).
